\begin{abstract}
We prove a representation-rigidity theorem for finite quantitative coding. Fix an integer capacity $b>1$. At depth $k$, consider the complete quantitative window of $b^k$ distinguishable states and let $\Code_k$ be an arbitrary finite code space. No positional syntax, digit alphabet, ordering, quotient, remainder, truncation rule, or carry algorithm is assumed on the code. The only finite-window hypotheses are losslessness---an injective encoding of all $b^k$ quantity states---and an optimal state budget $\card{\Code_k}\le b^k$. Finite cardinality forces equality $\card{\Code_k}=b^k$ and hence bijectivity of the encoding. Therefore every optimal lossless code is a change of coordinates of the canonical cyclic quantity window. Exact unit successor on the code is uniquely determined by conjugation, and its wrap event is equivalent to the carry-through-depth event formalized in Carry Geometry.

We then prove cross-depth rigidity. For every $k\le m$, the unique zero-preserving map from the depth-$m$ canonical cycle to the depth-$k$ cycle that commutes with unit successor is reduction modulo $b^k$. Transporting this result through arbitrary encoders yields a unique code-level projection. These projections are identities at equal depth and compose transitively, so every arbitrary optimal lossless tower is projectively equivalent, as a successor dynamical system, to the canonical residual/carry tower. Any two such towers with the same capacity are therefore projectively equivalent. A specialization to arbitrary finite local cells derives $b$ as the number of available local states. The complete result is formalized and kernel-checked in Lean~4. A complementary constructive branch of the repository independently derives quotient--remainder-like coordinates, carry transport, and canonical digits from explicit operational hypotheses.
\end{abstract}

\section{Introduction}

A representation of quantity may change symbols, labels, bit patterns, memory layout, or local coordinates without changing the quantity represented. This elementary fact suggests a structural question:

\begin{quote}
If a complete finite set of distinguishable quantities is represented exactly with no redundant finite states, how much of the quantitative dynamics is actually free to change?
\end{quote}

Ordinary positional notation suggests one answer. In base $b>1$, a depth-$k$ window has $b^k$ residue states. Unit increment acts cyclically on that window, and the transition from the maximal residue back to zero is the finite shadow of carry through the lowest $k$ places. Between depths, the lower state is obtained by reduction modulo the lower place value.

These statements are usually formulated inside a positional system. Digits, powers of a base, quotient and remainder, and a carry algorithm are already available. Our goal is different: we ask whether the same finite quantitative mechanics is forced when the code syntax is completely opaque.

Fix $b>1$ and write
\[
  \Window_k := \Fin(b^k).
\]
Let $\Code_k$ be any finite code type and suppose only that there is an injective encoding
\[
  e_k:\Window_k\hookrightarrow\Code_k
\]
with the finite-state budget
\[
  \card{\Code_k}\le b^k.
\]
No operation or ordering on $\Code_k$ is assumed.

The first rigidity step is cardinal:
\[
  b^k\le\card{\Code_k}\le b^k,
\]
so $e_k$ is bijective. Thus every optimal lossless finite code is a coordinate system on the same quantity window.

Define canonical successor
\[
  \Succ_k(n)=(n+1)\bmod b^k.
\]
Transporting $\Succ_k$ through $e_k$ gives an exact successor on the code. We prove that every exact successor implementation equals this transported map. Furthermore,
\[
  \Succ_k(n)=0
  \quad\Longleftrightarrow\quad
  n+1\equiv0\pmod{b^k},
\]
and the right-hand side is exactly the carry-through-depth predicate from the linked Carry Geometry formalization.

The second rigidity step concerns depth. For $k\le m$, any map
\[
  f:\Window_m\to\Window_k
\]
that fixes zero and commutes with unit successor is forced to be
\[
  f(n)=n\bmod b^k.
\]
Transported through arbitrary encoders, this determines the unique coherent map $\Code_m\to\Code_k$. The resulting maps satisfy
\[
  \Proj_{k,k}=\id,
  \qquad
  \Proj_{j,k}\circ\Proj_{k,m}=\Proj_{j,m}.
\]
Hence the whole code tower is projectively equivalent to the canonical residual/carry tower.

The principal Lean theorem is
\begin{center}
\lean{universal_optimal_lossless_representation_collapses_to_carry}.
\end{center}
It returns a \lean{UniversalCarryCollapseCertificate} packaging exact cardinality, bijectivity, successor conjugacy, carry/wrap equivalence, uniqueness of all cross-depth projections, residual naturality, and the projective laws.

\subsection{Contributions}

The formal development establishes:

This branch is not needed for the rigidity proof, but provides a non-circular emergence route to the familiar arithmetic objects.

\section{Optimal lossless finite representation}

\subsection{Finite quantity windows}

Fix $b>1$. At depth $k$, the complete quantitative window is the finite type
\[
  \Window_k=\Fin(b^k),
\]
whose elements represent the states $0,1,\dots,b^k-1$.

\subsection{Opaque code spaces}

\begin{definition}[Optimal lossless window]
An optimal lossless code for $\Window_k$ consists of a finite type $\Code_k$ and an encoding
\[
  e_k:\Window_k\to\Code_k
\]
that is injective and satisfies
\[
  \card{\Code_k}\le b^k.
\]
\end{definition}

In Lean this is \lean{LosslessCompressedWindow}. The word \emph{compressed} is used in an exact finite-state cardinal sense: no more code states are available than distinct quantities requiring representation. We are not making a Shannon-theoretic claim about variable-length codes.

No digit alphabet, positional order, place-value function, quotient, remainder, truncation operation, or native carry operation is assumed on $\Code_k$.

\begin{remark}[Arbitrary recodings]
A permutation of ordinary codes, a Gray-like encoding, a relabeling by opaque symbols, or any other bijective finite recoding lies inside this model. Such examples are not excluded; the theorem is designed to identify them as coordinate changes.
\end{remark}

\section{Cardinal rigidity}

\begin{theorem}[Exact state count]
For every optimal lossless window,
\[
  \card{\Code_k}=b^k.
\]
\end{theorem}

\begin{proof}
Injectivity gives $b^k=\card{\Window_k}\le\card{\Code_k}$. The state budget gives the reverse inequality. Antisymmetry yields equality.
\end{proof}

This is formalized as \lean{LosslessCompressedWindow.card_eq_windowSize}.

\begin{corollary}[Forced bijection]
The encoder $e_k$ is bijective, hence
\[
  \Window_k\simeq\Code_k.
\]
\end{corollary}

Lean theorem: \lean{LosslessCompressedWindow.encode_bijective}.

The conclusion is already representation-theoretic: in the optimal finite-state regime, exact recoverability leaves no unused code states and no collisions. Every code state carries exactly one quantitative state.

\section{Canonical successor and carry}

For $b>0$, define the canonical cyclic successor
\[
  \Succ_k(n)=(n+1)\bmod b^k.
\]
The Lean definition is \lean{windowSuccessor}. The distinguished zero state is \lean{windowZero}.

The linked Carry Geometry development defines carry through the lowest $k$ places by
\[
  n+1\equiv0\pmod{b^k}.
\]
In Lean the predicate is \lean{CarryGeometry.carryAfterIncrementAtDepth}.

\begin{theorem}[Canonical wrap is carry]
For every $n\in\Window_k$,
\[
  \Succ_k(n)=0
  \quad\Longleftrightarrow\quad
  \operatorname{carryAfterIncrementAtDepth}(b,k,n).
\]
\end{theorem}

This is \lean{windowSuccessor_eq_zero_iff_carry}.

The theorem identifies carry dynamically, before any statement about the visual syntax of an arbitrary code.

\section{Successor rigidity under arbitrary recoding}

Since $e_k$ is bijective, define
\[
  T_k=e_k\circ\Succ_k\circ e_k^{-1}.
\]
This is \lean{LosslessCompressedWindow.codeSuccessor}. The intertwining identity is
\[
  T_k(e_k(n))=e_k(\Succ_k(n)).
\]

\begin{theorem}[Unique exact successor]
Suppose $U:\Code_k\to\Code_k$ satisfies
\[
  U(e_k(n))=e_k(\Succ_k(n))
\]
for every $n\in\Window_k$. Then $U=T_k$.
\end{theorem}

Lean theorem: \lean{LosslessCompressedWindow.codeSuccessor_unique}.

\begin{proof}
Every $c\in\Code_k$ is $e_k(n)$ for some $n$, by surjectivity. Exactness determines $U(c)$ on that representative, so $U$ agrees pointwise with $T_k$.
\end{proof}

\begin{corollary}[Carry is invariant under optimal lossless recoding]
For any exact successor $U$,
\[
  U(e_k(n))=e_k(0)
  \quad\Longleftrightarrow\quad
  \operatorname{carryAfterIncrementAtDepth}(b,k,n).
\]
\end{corollary}

Lean theorem: \lean{LosslessCompressedWindow.exact_successor_wrap_iff_carry}.

An arbitrary recoding can hide the familiar ripple pattern in its raw symbols, but it cannot move the quantitative wrap event.

\section{Change of representation}

Let $\Code_k^{(1)}$ and $\Code_k^{(2)}$ be two arbitrary optimal lossless codes. Their forced coordinate change is
\[
  \Phi_k=e_k^{(2)}\circ(e_k^{(1)})^{-1}.
\]
Lean defines this as \lean{LosslessCompressedWindow.changeOfRepresentation}.

It preserves represented quantity and conjugates successor:
\[
  \Phi_k\circ T_k^{(1)}=T_k^{(2)}\circ\Phi_k.
\]
The corresponding theorem is \lean{changeOfRepresentation_conjugates_successor}.

Thus the finite quantitative successor is an invariant of the represented quantity window, not of a particular code syntax.

\section{All finite depths}

A full arbitrary tower is formalized by \lean{LosslessCompressedTower}. At each depth $k$ the code type may be different and opaque.

Lean proves simultaneously:
\[
  \card{\Code_k}=b^k,
  \qquad
  \Code_k\simeq\Window_k,
\]
and carry conjugacy at every depth. The principal theorem at this stage is \lean{LosslessCompressedTower.all_depths_force_carry_conjugacy}.

Levelwise rigidity alone leaves one possible freedom: the maps connecting different depths. We now remove that freedom.

\section{Cross-depth rigidity}

\subsection{Canonical residual maps}

For $k\le m$, define
\[
  \rho_{k,m}(n)=n\bmod b^k,
  \qquad
  \rho_{k,m}:\Window_m\to\Window_k.
\]
Lean definition: \lean{canonicalDepthProjectionLE}.

These maps preserve zero and commute with unit successor:
\[
  \rho_{k,m}(0)=0,
  \qquad
  \rho_{k,m}\circ\Succ_m=\Succ_k\circ\rho_{k,m}.
\]

\begin{theorem}[Cross-depth rigidity]
Let $k\le m$ and let $f:\Window_m\to\Window_k$ satisfy
\[
  f(0)=0
\]
and
\[
  f(\Succ_m(n))=\Succ_k(f(n))
\]
for every $n$. Then
\[
  f=\rho_{k,m}.
\]
\end{theorem}

Lean theorem: \lean{canonicalDepthProjectionLE_unique}.

\begin{proof}[Proof idea]
The cyclic successor generates every element of $\Window_m$ from zero. The value of $f$ at zero is prescribed, and successor equivariance recursively prescribes $f$ on the entire cycle. The residual map satisfies the same two laws, so the two maps coincide.
\end{proof}

This is a key rigidity statement: no native digit-truncation rule is assumed, yet the only quantity-coherent factor map is modulo reduction.

\section{Projective laws}

The residual maps satisfy
\[
  \rho_{k,k}=\id
\]
and, for $j\le k\le m$,
\[
  \rho_{j,k}\circ\rho_{k,m}=\rho_{j,m}.
\]
The Lean theorems are \lean{canonicalDepthProjectionLE_refl} and \lean{canonicalDepthProjectionLE_comp}.

Hence the canonical finite quantity windows form a projective system. This is the familiar finite-factor architecture of the constant-base adding machine or odometer, but the following section shows that arbitrary optimal code towers are forced to realize the same system.

\section{Projective rigidity in opaque coordinates}

For arbitrary code levels $\Code_m$ and $\Code_k$, define
\[
  P_{k,m}=e_k\circ\rho_{k,m}\circ e_m^{-1}.
\]
Lean definition: \lean{LosslessCompressedWindow.codeDepthProjectionLE}.

\begin{theorem}[Unique code-level projection]
Any $F:\Code_m\to\Code_k$ that preserves represented zero and commutes with exact code successor satisfies
\[
  F=P_{k,m}.
\]
\end{theorem}

Lean theorem: \lean{LosslessCompressedWindow.codeDepthProjectionLE_unique}.

Existence and uniqueness are packaged by the corresponding \lean{existsUnique_codeDepthProjectionLE} theorem.

For arbitrary towers, Lean defines \lean{LosslessCompressedTower.forcedProjection} and proves:
\begin{align*}
  P_{k,k}&=\id,\\
  P_{j,k}\circ P_{k,m}&=P_{j,m}.
\end{align*}
The packaged theorem is \lean{LosslessCompressedTower.universal_projective_tower_laws}.

Therefore the arbitrary code tower is not only levelwise conjugate to the canonical cycles. Its entire depth hierarchy is forced.

\section{Universal carry-collapse capstone}

The final Lean proposition is \lean{UniversalCarryCollapseCertificate}. It records eight simultaneous facts:
\begin{enumerate}[label=(\arabic*)]
\item exact cardinality at every level;
\item bijectivity of every encoder;
\item successor conjugacy;
\item carry/wrap equivalence;
\item uniqueness of every ordered cross-depth projection;
\item residual naturality of those projections;
\item identity projection at equal depth;
\item transitive projective composition.
\end{enumerate}

\begin{theorem}[Universal carry-collapse theorem]
Let $b>1$ and let $\Code=(\Code_k)_{k\in\N}$ be any \lean{LosslessCompressedTower b}. Then $\Code$ satisfies \lean{UniversalCarryCollapseCertificate}. In particular, it is projectively equivalent, as an exact successor dynamical system, to the canonical residual/carry tower.
\end{theorem}

Lean theorem:
\begin{center}
\lean{universal_optimal_lossless_representation_collapses_to_carry}.
\end{center}

The conclusion may be summarized as
\[
\boxed{
\begin{gathered}
\text{optimal lossless finite quantitative representation}\\
\Longrightarrow\\
\text{residual/carry projective dynamics up to change of coordinates}.
\end{gathered}
}
\]

The word ``collapse'' refers to quotienting out representational coordinates. Different codes may remain visually and computationally different, but there is no second exact quantitative successor or coherent depth hierarchy left after conjugacy is taken into account.

\section{Equivalence of arbitrary optimal towers}

The formalization proves the direct comparison theorem
\begin{center}
\lean{any_two_optimal_lossless_towers_are_projectively_equivalent}.
\end{center}

If $\Code$ and $\mathcal{D}$ are two optimal lossless towers with the same capacity $b$, the canonical levelwise equivalences $\Phi_k:\Code_k\simeq\mathcal{D}_k$ satisfy
\[
  \Phi_k\circ T_k^{\Code}=T_k^{\mathcal{D}}\circ\Phi_k
\]
and
\[
  \Phi_k\circ P_{k,m}^{\Code}
  =P_{k,m}^{\mathcal{D}}\circ\Phi_m.
\]

Thus representation change preserves the full successor/projective mechanics.

\section{Finite local cells}

Let \lean{Local} be any finite local state type and define a depth-$k$ code by
\[
  \operatorname{LocalWord}(\mathrm{Local},k)=\Fin(k)\to\mathrm{Local}.
\]
No positional semantics is built into this type. Its cardinality is
\[
  \card{\operatorname{LocalWord}(\mathrm{Local},k)}
  =\card{\mathrm{Local}}^k.
\]
Set
\[
  b=\card{\mathrm{Local}}.
\]
Any injective encoding
\[
  \Fin(b^k)\to\operatorname{LocalWord}(\mathrm{Local},k)
\]
is therefore automatically bijective.

The theorem
\begin{center}
\lean{universal_finiteLocal_lossless_representation_collapses_to_carry}
\end{center}
then supplies the complete universal certificate.

This specialization captures the slogan
\[
\boxed{
\text{finite local capacity}
+
\text{complete exact quantitative occupancy}
\Longrightarrow
\text{carry projective dynamics up to coordinates}.
}
\]

\section{Complementary constructive route}

The universal theorem is a rigidity result: it starts from the complete finite quantity windows and proves that optimal lossless recoding cannot alter their mechanics.

The repository also contains a complementary constructive program. Its formal chain is
\[
\begin{gathered}
\text{finite-state obstruction}
\to\text{information escape}
\to\text{unbounded distinguishing depth}
\to\text{unit dynamics}\\
\to\text{local recurrence}
\to\text{emergent capacity}
\to\text{cycle coordinates}
\to\text{emergent quotient/remainder}\\
\to\text{boundary transport}
\to\text{carry}
\to\text{finite positional expansion}
\to\text{intrinsic digit uniqueness}.
\end{gathered}
\]

The construction intentionally avoids using natural-number division or modulo to define the emergent coordinates, and avoids using \lean{Nat.digits} to define the emergent digit list. Classical operations appear only as downstream uniqueness-based crosswalks.

Representative theorems include \lean{existsUnique_emergentLocalCapacity}, \lean{existsUnique_cycleCoordinates}, \lean{emergentQuotientRemainder_spec}, \lean{emergent_step_at_boundary_is_oneCarry}, \lean{emergent_weighted_positional_transport}, and \lean{existsUnique_intrinsicCanonicalExpansion}.

The earlier \lean{existsUnique_foundationalCapstone} remains a valid theorem packaging one explicit operational emergence route. It is no longer the maximal theorem of the repository.

The two branches answer different questions:
\begin{itemize}
\item \emph{construction}: how can quotient/remainder, carry, and canonical digits be built without assuming them?
\item \emph{rigidity}: can optimal lossless recoding create a genuinely different exact quantitative mechanics?
\end{itemize}
The universal theorem answers the second question negatively.

\section{Related work}

\subsection{Numeration and automata}

Finite automata and transducers have long been used to study normalization and arithmetic in established numeration systems \cite{Frougny1992,Frougny1999,FrougnySakarovitch2010}. Abstract numeration systems and generalized radix systems broaden the possible representation languages \cite{LecomteRigo2010,Rigo2014,AkiyamaPetho2002,AkiyamaEtAl2004}.

These theories normally include a numeration architecture in the input. Our code type is opaque. The contribution is therefore a rigidity theorem about exact finite quantitative coding rather than a new normalization algorithm for a prescribed language.

\subsection{Carry propagation}

Berth\'e, Frougny, Rigo, and Sakarovitch study carry propagation of successor in several classes of numeration systems \cite{BertheFrougnyRigoSakarovitch2020}; signed-digit carry phenomena are also studied by Heuberger, Kropf, and Prodinger \cite{HeubergerKropfProdinger2017}. These works begin with an established representation system and analyze digit changes under successor.

Our theorem addresses an invariant finite event upstream of such statistics: the wrap corresponding to carry cannot be removed by optimal lossless recoding.

\subsection{Odometers and adding machines}

Odometers are the closest dynamical neighbor. Classical constructions use finite cyclic factors, addition by one, and inverse/projective systems with residual connecting maps \cite{GrabnerLiardetTichy1995,BaratBertheLiardetThuswaldner2006}.

We do not claim that odometer dynamics or inverse limits are new. The theorem direction is different. Rather than constructing a projective cyclic system and studying it, we start with arbitrary opaque optimal finite codes and prove that their exact successor and every coherent cross-depth map are uniquely conjugate to that system. The result can therefore be read as a finite projective rigidity theorem whose canonical representative is the base-$b$ odometer tower.

\subsection{Information-lossless finite-state coding}

Finite-state dimension is characterized using information-lossless finite-state compressors \cite{DaiLathropLutzMayordomo2004}. The shared theme is preservation of distinguishability under finite-state representation. That literature studies asymptotic compression of sequences, whereas the present theorem concerns complete finite quantity windows under an exact cardinal budget and derives successor/projective rigidity from the resulting bijectivity.

\subsection{Periodic enumeration}

Manca derives a positional base recurrence from a periodic monotone enumeration system \cite{Manca2024}. This is an important structural precedent for deriving positional equations from periodic organization. Manca's framework already includes numeral strings and a period. Our universal branch assumes no numeral syntax on the arbitrary code; the complementary constructive branch separately derives a local capacity before canonical digits are introduced.

\subsection{Novelty statement}

The literature surveyed here already contains finite-state numeration, carry dynamics, adding machines, projective cyclic factors, information-lossless coding, and derivations of positional equations from periodic systems. We therefore make no claim that those ingredients are individually new.

The scoped contribution is the following implication: arbitrary opaque optimal lossless finite codes of the complete $b^k$ quantity windows are forced, at every depth and across every ordered pair of depths, to be conjugate/projectively equivalent to the canonical residual/carry system. We did not find this exact rigidity statement in the literature reviewed for this manuscript. This is a scoped observation, not an exhaustive historical priority claim.

\section{Scope and limitations}

The theorem is universal within a precise class. At depth $k$, it assumes an injective map
\[
  e_k:\Fin(b^k)\hookrightarrow\Code_k
\]
with
\[
  \card{\Code_k}\le b^k.
\]
This is the formal notion of optimal finite-state lossless coding used here.

Several distinctions are important.

First, redundant codes with $\card{\Code_k}>b^k$ may contain non-quantitative degrees of freedom. The theorem does not claim that those redundant states disappear.

Second, this is not an asymptotic source-coding theorem about probability distributions or variable-length descriptions.

Third, carry is asserted dynamically and invariantly. A recoded implementation need not display a visually recognizable ripple-carry pattern in its raw symbols.

Fourth, the result does not classify all possible numeration languages as syntactic fixed-radix systems. It proves that an optimal lossless code for the complete $b^k$ quantity windows has no different exact successor/projective mechanics after coordinate change.

\section{Discussion: conservation under representation change}

The main theorem is naturally interpreted as a conservation principle. A change of representation may alter the appearance of code states, but under optimal finite-state losslessness it cannot alter:
\begin{itemize}
\item the number of quantitative states at depth $k$;
\item the exact unit-successor orbit;
\item the quantitative wrap/carry event;
\item the unique coherent reduction from a deeper window to a shallower one;
\item the projective composition law of those reductions.
\end{itemize}

In dynamical language, all optimal lossless codes realize the same finite adding-machine factors. In projective language, they are isomorphic presentations of the same residual tower. In positional language, the canonical representative is the carry hierarchy.

The conserved object is therefore not a particular numeral spelling. It is quantitative information together with its exact successor and depth-consistency structure.

\section{Conclusion}

We formalized a universal rigidity theorem for optimal lossless finite representation of quantity. At each depth, injectivity and the optimal state budget force an arbitrary finite code to have exactly the cardinality of the complete quantity window, hence to be bijective with it. Exact unit successor is unique up to conjugacy, and its wrap event is exactly the carry-through-depth event. Across depths, zero preservation and successor equivariance force residual reduction modulo the lower capacity. These maps satisfy identity and projective composition laws. Consequently every arbitrary optimal lossless tower is projectively equivalent to the canonical residual/carry tower, and any two such towers are equivalent through changes of representation preserving the complete quantitative mechanics.

For arbitrary finite local cells, the capacity parameter is simply the number of available local states, so the theorem applies without assigning positional semantics to those cells in advance.

A complementary formal branch constructs emergent quotient--remainder coordinates, carry transport, and canonical positional digits from explicit operational hypotheses. Together, the two branches separate construction from rigidity: one explains how familiar arithmetic coordinates can arise without circular definitions; the other proves that optimal lossless recoding cannot escape the residual/carry projective dynamics.
